# Model and Evaluation

## Feature order

The current model bundle uses:
- mean_hr
- rmssd
- sdnn
- mean_nn
- pnn50

The deployment receives HR, HRV and RMSSD and derives the remaining fields.

## Random Forest

The training workflow records:
- n_estimators = 200
- max_depth = 10
- min_samples_leaf = 3
- class_weight = balanced
- random_state = 42

## Hybrid layer

High is reinforced at HR >= 105, HRV <= 45 and RMSSD <= 35.

Moderate is reinforced at HR >= 90, HRV <= 55 and RMSSD <= 45 when the model predicts Normal.

These are prototype heuristics, not clinical thresholds.

## Evaluation

LOSO evaluation over S3, S4 and S5:
- S3: 77.51%
- S4: 67.14%
- S5: 64.65%
- Mean: 69.77%
- Standard deviation: 5.57%

The evaluation is preliminary and includes only three subjects.

## Implementation note

The backend pNN50 value is generated by the supplied deployment formula based on RMSSD and HRV. It is not a raw interval-series pNN50 recomputation.
